# Steam-investment-calculator
О проекте:
Совместный проект калькулятора для подсчета цен скинов в Counter-Strike 2.
Важно: Детали проекта хранятся в секрете, этот файл содержит только общую структуру.

Цели проекта:
Создать точный калькулятор цен скинов CS2,
Интеграция с актуальными рыночными данными,
Кросс-платформенная доступность (ПК + мобильные устройства).

Этапы разработки:
1. Бэкенд:
Исследование API Steam,
Анализ доступных методов Steam Web API,
Изучение Steam Market API,
Проверка лимитов и условий использования,
Тестирование запросов для получения цен скинов.

2. Логика калькулятора:
Определение алгоритма расчета ,
Реализация кэширования данных,
Разработка системы обновления цен,
Создание API endpoints для фронтенда.

3. Фронтенд:
Дизайн приложения,
Создание дизайн-системы,
Прототипирование интерфейса,
Адаптация под разные разрешения экрана,
Разработка приложения,
Настройка проекта (React/Vue/другое),
Реализация основных компонентов,
Интеграция с бэкенд API,
Тестирование UI/UX,
Кросс-платформенная адаптация,
Адаптация под мобильные устройства,
PWA-функциональность (опционально),
Оптимизация производительности.

Конфиденциальность:
Не раскрывать детали реализации публично,
Хранить чувствительные данные (API ключи) в .env файлах,
Не коммитить конфиденциальную информацию в репозиторий.

Запуск разработки:
Клонировать репозиторий,
Установить зависимости для бэкенда и фронтенда,
Настроить переменные окружения,
Запустить локальные серверы.
